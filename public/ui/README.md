Carpeta UI — estilos y utilidades

Archivos incluidos:

- `styles.css`: Variables CSS, estilo de tarjetas (`card`), contenedor (`container`), hero, botones (`btn-primary`, `btn-secondary`) y animaciones suaves.

Cómo usar:

1. Enlazar el CSS desde tu `index.html` con `ui/styles.css` (ya se añadió en `public/index.html`).
2. Añadir la clase `container` al main o al contenedor principal.
3. Envolver secciones en `card` para obtener fondo, sombreado y animación suave.
4. Usar `btn-primary` y `btn-secondary` en los botones para estilos coherentes.

Accesibilidad:

- Las animaciones respetan la preferencia `prefers-reduced-motion`.

Extensiones:

- Si quieres más componentes (modales, toasts), puedo añadirlos aquí con los estilos y ejemplos JS.
